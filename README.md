# Global Superstore Sales Dashboard

## Overview

This project presents an interactive Tableau dashboard built using the Global Superstore dataset. It provides insights into sales performance, profit trends, regional distribution, and product category analysis to support business decision-making.



## Dashboard Features

-  Total Sales KPI
-  Sales by Region (Interactive Map)
-  Sales Trend Over Time
-  Sales by Category
-  Discount vs Profit Analysis
-  Profit vs Sales Scatter Plot
-  Top Sub-Categories Analysis
- Country Filter for Interactive Exploration

---

## Tools Used

- Tableau Public
- Microsoft Excel / CSV Dataset

---

## Key Insights

- Technology generated the highest sales among product categories.
- Sales showed a consistent upward trend over the years.
- Regional analysis highlights differences in sales performance across countries.
- Profitability varies significantly across product sub-categories.
- Interactive filters allow users to explore country-specific trends.
